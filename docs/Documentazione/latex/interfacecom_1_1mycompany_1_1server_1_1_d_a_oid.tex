\doxysubsection{Detailed Description}
Interfaccia generica DAO (Data Access Object).

Definisce le operazioni CRUD standard che ogni DAO del sistema deve implementare. Il tipo generico {\ttfamily T} rappresenta il modello gestito dalla specifica implementazione.
