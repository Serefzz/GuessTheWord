\doxysubsection{Detailed Description}
Server di gioco che accetta le connessioni dei client.

Gira in un thread daemon separato avviato da {\ttfamily \doxylink{classcom_1_1mycompany_1_1server_1_1_server_app}{Server\+App}}. Il ciclo principale accetta due socket, crea i rispettivi {\ttfamily \doxylink{classcom_1_1mycompany_1_1server_1_1_client_handler}{Client\+Handler}}, li collega come avversari e li avvia in thread separati. Il ciclo si ripete indefinitamente per supportare sessioni multiple.

La porta viene letta da {\ttfamily server.\+properties} (chiave {\ttfamily server.\+port}); se il file non esiste usa la porta di default {\ttfamily 5000}.
