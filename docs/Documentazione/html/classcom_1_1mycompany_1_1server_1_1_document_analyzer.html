Detailed Description

Analizza documenti di testo per estrarre statistiche di frequenza delle parole e suddividere il testo in frasi utilizzabili come sfide di gioco.

Utilizza Stream API per il calcolo della Term Frequency (TF).

Calcola la Term Frequency (TF) di tutte le parole nella frase indicata. Le parole vengono normalizzate in maiuscolo e filtrate: solo sequenze di lettere alfabetiche vengono considerate.
