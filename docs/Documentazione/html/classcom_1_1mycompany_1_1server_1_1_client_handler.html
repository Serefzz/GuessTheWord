Detailed Description

Gestisce la comunicazione con un singolo client connesso.

Ogni istanza gira in un thread separato avviato da GameServer. L'avversario viene impostato tramite setAvversario(ClientHandler) prima dell'avvio del thread.

Le frasi e le TF sono condivise staticamente tra tutti gli handler e vengono impostate dall'admin tramite AdminController.
