Detailed Description

Tipi di messaggio del protocollo client-server.

I messaggi Client -> Server vengono inviati dal client: LOGIN, REGISTRAZIONE, AVVIA_PARTITA, RISPOSTA, FORFAIT, STORICO_REQUEST, CLASSIFICA_REQUEST, DISCONNETTI.

I messaggi Server -> Client vengono inviati dal server: OK, ERRORE, ATTESA, SFIDA, RISPOSTA_ERRATA, RISULTATO_VINTO, RISULTATO_PERSO, PAREGGIO, STORICO_RESPONSE, CLASSIFICA_RESPONSE.
