Detailed Description

Gestore centralizzato del database SQLite dell'applicazione.

Fornisce l'URL di connessione JDBC usato da tutti i DAO e il metodo inizializza() da chiamare una sola volta all'avvio del server.

Utente admin di default: username admin, password admin (hash SHA-256). Viene inserito con INSERT OR IGNORE, quindi non sovrascrive un admin già presente.
