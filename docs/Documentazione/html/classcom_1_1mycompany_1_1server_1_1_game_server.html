Detailed Description

Server di gioco che accetta le connessioni dei client.

Gira in un thread daemon separato avviato da ServerApp. Il ciclo principale accetta due socket, crea i rispettivi ClientHandler, li collega come avversari e li avvia in thread separati. Il ciclo si ripete indefinitamente per supportare sessioni multiple.

La porta viene letta da server.properties (chiave server.port); se il file non esiste usa la porta di default 5000.
