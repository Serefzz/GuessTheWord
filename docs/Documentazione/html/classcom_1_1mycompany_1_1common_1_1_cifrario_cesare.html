Detailed Description

Implementazione del Cifrario di Cesare per lettere maiuscole.

Ogni lettera viene spostata in avanti (cifratura) o indietro (decifratura) di un numero fisso di posizioni nell'alfabeto. I caratteri non alfabetici rimangono invariati.

Questa classe non è istanziabile (costruttore privato).
