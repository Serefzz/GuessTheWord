Detailed Description

Messaggio scambiato tra client e server via socket.

Formato stringa: TIPO|param0|param1|... Compatibile con java.io.BufferedWriter / java.io.BufferedReader.

Ogni messaggio è immutabile: tipo e parametri vengono impostati nel costruttore e non possono essere modificati.
