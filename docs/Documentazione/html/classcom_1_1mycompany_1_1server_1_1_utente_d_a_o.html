Detailed Description

DAO per la tabella Utente del database SQLite.

Implementa DAOusernameUtente

Le password vengono sempre salvate come hash SHA-256 tramite hashPassword(String). Ogni metodo apre e chiude la propria connessione JDBC con try-with-resources (versione con connessione non persistente).
