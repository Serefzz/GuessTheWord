Detailed Description

Interfaccia generica DAO (Data Access Object).

Definisce le operazioni CRUD standard che ogni DAO del sistema deve implementare. Il tipo generico T rappresenta il modello gestito dalla specifica implementazione.

Implementazioni presenti:

PartitaDAO — gestisce la tabella Partita FraseDAO — gestisce la tabella Frase DocumentoDAO — gestisce la tabella Documento

<T>il tipo di entità gestita dal DAO
